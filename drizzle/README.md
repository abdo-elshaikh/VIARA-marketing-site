# Drizzle Database Migrations

## Overview
SQLite schema migrations and metadata generated by Drizzle Kit for the VIARA marketing site Cloudflare D1 database. Manages sequential schema evolution across versions defining tables (`inquiries`, `reviews`, `site_settings`, `site_revisions`), single/composite indexes, and schema alterations.

## Interface
- `[0000_dry_sentry.sql:inquiries]` - Initial inquiries table and composite index
- `[0000_dry_sentry.sql:inquiries_user_created_idx]` - Index on `inquiries(user_id, created_at)`
- `[0001_illegal_multiple_man.sql:reviews]` - Reviews table and composite index
- `[0001_illegal_multiple_man.sql:reviews_status_created_idx]` - Index on `reviews(status, created_at)`
- `[0001_illegal_multiple_man.sql:site_settings]` - Site settings key-value store
- `[0001_illegal_multiple_man.sql:inquiries.locale]` - Inquiry locale column addition
- `[0001_illegal_multiple_man.sql:inquiries.offer]` - Inquiry offer tracking column addition
- `[0002_superb_zzzax.sql:reviews.system_id]` - Associated healthcare system ID column on reviews
- `[0003_soft_dragon_man.sql:site_revisions]` - Content revisions table
- `[0003_soft_dragon_man.sql:site_revisions_version_idx]` - Index on `site_revisions(version)`
- `[meta/_journal.json:entries]` - Drizzle Kit migration journal tracking sequential application

## Invariants
- `[0000_dry_sentry.sql:inquiries.id]` PRIMARY KEY NOT NULL
- `[0000_dry_sentry.sql:inquiries.status]` DEFAULT 'new' NOT NULL
- `[0001_illegal_multiple_man.sql:reviews.id]` PRIMARY KEY NOT NULL
- `[0001_illegal_multiple_man.sql:reviews.locale]` DEFAULT 'ar' NOT NULL
- `[0001_illegal_multiple_man.sql:reviews.status]` DEFAULT 'pending' NOT NULL
- `[0001_illegal_multiple_man.sql:reviews.consent]` DEFAULT 1 NOT NULL
- `[0001_illegal_multiple_man.sql:site_settings.key]` PRIMARY KEY NOT NULL
- `[0001_illegal_multiple_man.sql:site_settings.version]` DEFAULT 1 NOT NULL
- `[0003_soft_dragon_man.sql:site_revisions.id]` PRIMARY KEY NOT NULL

## Side Effects
- `[0000_dry_sentry.sql:CREATE TABLE inquiries]` Creates inquiries table and inquiries_user_created_idx index in SQLite database
- `[0001_illegal_multiple_man.sql:CREATE TABLE reviews]` Creates reviews table and reviews_status_created_idx index in SQLite database
- `[0001_illegal_multiple_man.sql:CREATE TABLE site_settings]` Creates site_settings table in SQLite database
- `[0001_illegal_multiple_man.sql:ALTER TABLE inquiries]` Alters inquiries table adding locale and offer columns in SQLite database
- `[0002_superb_zzzax.sql:ALTER TABLE reviews]` Alters reviews table adding system_id column in SQLite database
- `[0003_soft_dragon_man.sql:CREATE TABLE site_revisions]` Creates site_revisions table and site_revisions_version_idx index in SQLite database
