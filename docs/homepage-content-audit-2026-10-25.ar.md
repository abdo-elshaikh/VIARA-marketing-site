# مراجعة محتوى الرئيسية وتنفيذ الهيرو — 25 أكتوبر 2026

## ما تغير

أعيد بناء الهيرو بمقدمة قابلة للتحرير ومعاينة لواجهات RIS وPACS والمواعيد. تستخدم المعاينة أول لقطة لكل منتج من `lib/system-captures.ts`، وتعرض المنتجات المفعلة فقط. الصور المختارة محفوظة من النسخة المحلية وليست دليلًا على تشغيل عميل أو نتائج أداء. يمكن فتح الصورة بالحجم الكامل، ويُمرر المنتج المختار ونوع المنشأة إلى نموذج الطلب. عند تعطيل المنتجات الثلاثة تظهر مقدمة بديلة دون معاينة منتج معطل.

أصبحت الرئيسية: مقدمة ومعاينة ← حلول مفعلة وروابط تفاصيلها ← تعريف مختصر اختياري ← رابط التخطيط ← مراجعات منشورة عند توفرها ← أسئلة ← الطلب. أزيلت أقسام المجالات العامة ومحدد المنشأة ومراحل التنفيذ المطولة لتجنب تكرار الدليل وصفحة التخطيط. يبقى محتوى الهيرو والتعريف والمنتجات من `SiteContent`، وتستخدم النصوص المساندة `useSiteText`.

## التحقق وحدوده

- نجح `npm run typecheck`.
- نجح `npm run lint` مع تحذيرات، منها استخدام الصور المباشرة وتحذيرات في ملفات أخرى.
- نجح `npm test`: عدد 18 اختبار Node وثلاثة اختبارات ترحيل قاعدة البيانات.
- نجح `npm run build`.
- استجابت `/` و`/en` برمز 200 عبر خادم التطوير المحلي، واحتوت الاستجابة الهيرو الجديد ولقطة قائمة العمل. تحققت الاستجابة من عرض عنوان عربي وإنجليزي محفوظين في المحتوى.
- لم تتوفر أداة متصفح متصلة لإكمال المعاينة البصرية أو تجربة التبديل ولوحة المفاتيح والهاتف. قواعد الهاتف واتجاهي العرض موجودة، لكن فحصها بصريًا يبقى خطوة مطلوبة قبل الاعتماد النهائي.

النطاق هنا صفحة البداية المشتركة بالعربية والإنجليزية. لم تُراجع بقية صفحات الحلول والباقات أو كل نص محفوظ في قاعدة البيانات مراجعة إثبات مستقلة.

## جولة التطوير الإضافية

- أصبحت معاينة النظام داخل مساحة خضراء داكنة مع إطار نافذة وشريط يوضح المنتج المختار، مع تجنب شارات الاعتماد ومؤشرات الأداء الوهمية.
- يمكن تكبير اللقطة في حوار أصلي داخل الصفحة. يحتفظ رابط الصورة بإمكانية فتح الملف عند غياب JavaScript. الحوار يستخدم `showModal` للإغلاق بـEscape وحصر التركيز، مع زر إغلاق واضح.
- أضيف اختيار بين قائمة عمل RIS وقائمة غرف الفحص. يستخدم الهيرو قائمة صريحة للشاشات المحلية المراجعة: `worklist` و`modality` و`matching` و`appointments`؛ لا تُسحب صور AI أو العارض تلقائيًا كدليل على القدرات.
- أضيفت لقطات مصغرة لبطاقات RIS وPACS وCMS، مع أيقونات لبقية الحلول دون إسناد صور غير مطابقة إليها. يتكيف توزيع البطاقات مع عدد المنتجات المفعلة.
- أصبح التخطيط قسمًا مستقلًا يربط بمقارنة الباقات ويفتح حاسبة الأرشفة. توصف مخرجات الحاسبة كتقديرات تخطيطية.
- استبدلت حركة انزلاق المراجعات بعرض مراجعة واحدة؛ تُعطل أزرار السابق والتالي عند الحدود وتراعي اتجاه اللغة. لا توجد مراجعات مولدة أو أرقام تقييمات افتراضية.
- أزيل إخفاء أقسام الرئيسية إلى أن يعمل مراقب التمرير. يبقى المحتوى ظاهرًا عند تعطل JavaScript أو عدم توفر مراقب التقاطع.
- أعيد تشغيل فحص الأنواع وlint والاختبارات والبناء بنجاح. أعاد HTTP رمز 200 للعربية والإنجليزية، وظهرت معالم الحوار والتخطيط وبطاقات الصور دون خطأ عرض من الخادم. لا يزال اتصال أداة المتصفح غير متوفر، لذلك لم تُعتمد المعاينة البصرية أو التفاعلات كاختبارات ناجحة.

## الصور المولدة والتنقل التلقائي

بناءً على طلب إضافة صور تتضمن البراند، وُلّدت خمس صور عبر أداة `image_gen` المدمجة باستخدام `viara-brand-logo-only.png` مرجعًا بصريًا للهوية: RIS وPACS وCMS وAI وPORTAL. راجعت الصور بصريًا عند صدورها؛ تحمل رمز VIARA واسمها ضمن مشاهد ثلاثية الأبعاد بألوان الأخضر والعاجي والذهبي. لا تتضمن أرقام أداء أو ادعاءات اعتماد. صور الأشعة داخل التكوينات مولدة وتوضيحية، وليست دليلًا سريريًا.

المخرجات داخل `public/assets/systems/hero-20261025/`: لكل نظام ملف PNG أصلي وWebP للعرض. الأبعاد 1586×992 بكسل، وحجم كل WebP بين نحو 86 و114 ألف بايت. لم تُستبدل اللقطات الأصلية. النصوص الكاملة المستخدمة في التوليد ومسارات الملفات محفوظة في `docs/hero-imagegen-prompts-2026-10-25.json`.

تستخدم الرئيسية هذه الصور في الهيرو وبطاقات الحلول، وتوضح أنها صور مولدة وليست واجهات فعلية. يمكن التبديل إلى لقطات التطبيق المحلية المراجعة لـRIS وPACS وCMS. لا تُستخدم لقطات AI غير المطابقة كدليل بديل.

التنقل التلقائي كل 6500 مللي ثانية بين المنتجات المفعلة فقط. يتوقف مؤقتًا أثناء مرور مؤشر الفأرة، أو وجود تركيز داخل المعاينة، أو إخفاء تبويب المتصفح. الاختيار اليدوي وفتح التكبير وطلب العرض يوقفانه إلى أن يُستأنف بزر التشغيل. يُعطل التدوير عند تفعيل `prefers-reduced-motion`، ولا تُعلن تغييرات التدوير التلقائي لقارئ الشاشة. تُحمّل الصورة التالية مسبقًا، ويظهر شريط زمني أثناء التدوير.

أضيفت اختبارات للمنتجات المفعلة واستبعاد المجالات الأخرى، والالتفاف في ترتيب الأنظمة، وحالات غياب المنتجات أو حذف الاختيار الحالي، ووجود ملفات الصور والنصوص الثنائية اللغة. نجح فحص الأنواع وlint (مع تحذيرات) والبناء، و21 اختبار Node وثلاثة اختبارات ترحيل. أعادت الملفات الخمسة رمز 200 ونوع `image/webp`، وظهرت صور البراند وأداة التدوير والتوضيح التحريري في استجابة العربية والإنجليزية دون خطأ عرض من الخادم. هذه الاختبارات لا تحل محل تجربة المؤقت والتركيز والتكبير فعليًا في المتصفح؛ تعذر ذلك لاستمرار عدم اتصال أداة المتصفح.
