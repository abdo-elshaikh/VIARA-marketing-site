## 🖼️ Image SEO Optimization

### Alt Text Best Practices

#### ❌ Bad Alt Text
```html
<img src="ris.png" alt="RIS" />
<img src="screenshot.png" alt="screenshot" />
<img src="logo.png" alt="logo" />
```

#### ✅ Good Alt Text

**Hero Image**:
```tsx
<img 
  src="/assets/scenes/viara-brand-hero-v3.webp"
  alt={t(
    'صورة توضيحية لنظام VIARA بألوان الأخضر والذهبي داخل مركز أشعة حديث',
    'VIARA system illustrated in green and gold within a modern radiology center'
  )}
/>
```

**System Screenshot**:
```tsx
<img 
  src="/assets/system/ris-worklist.webp"
  alt={t(
    'واجهة قائمة عمل نظام RIS تعرض المواعيد وبيانات المرضى',
    'RIS worklist interface showing appointments and patient data'
  )}
/>
```

**Logo**:
```tsx
<img 
  src="/assets/viara-symbol.webp"
  alt={t('شعار VIARA', 'VIARA logo')}
/>
```

**Decorative Image**:
```tsx
<img 
  src="/assets/decoration.webp"
  alt=""
  aria-hidden="true"
/>
```

### Image File Naming

#### ❌ Bad Names
- `IMG_1234.png`
- `screenshot.png`
- `pic1.webp`

#### ✅ Good Names
- `ris-worklist-interface.webp`
- `pacs-dicom-viewer-screenshot.webp`
- `medical-center-dashboard.webp`
- `viara-logo.webp`

### Image Optimization Checklist

For each image:
- [ ] Descriptive filename
- [ ] Meaningful alt text (keywords when natural)
- [ ] WebP format
- [ ] Optimized size (< 500KB)
- [ ] Proper dimensions (not oversized)
- [ ] Lazy loading for below-fold images

### Recommended Additions

#### SoftwareApplication Schema (for solution pages)

**File**: `lib/seo.ts`

```typescript
export function softwareApplicationSchema(product: Product, locale: Locale) {
  return {
    '@context': 'https://schema.org',
    '@type': 'SoftwareApplication',
    'name': txt(product.name, locale),
    'applicationCategory': 'HealthApplication',
    'operatingSystem': 'Web',
    'offers': {
      '@type': 'Offer',
      'price': '0',
      'priceCurrency': 'SAR',
      'availability': 'https://schema.org/InStock',
      'description': txt(product.description, locale)
    },
    'featureList': product.features.map(f => txt(f.name, locale)),
    'inLanguage': [locale],
    'audience': {
      '@type': 'Audience',
      'audienceType': 'Healthcare Professionals'
    }
  };
}
```

#### BreadcrumbList Schema

```typescript
export function breadcrumbSchema(items: { name: string; url: string }[]) {
  return {
    '@context': 'https://schema.org',
    '@type': 'BreadcrumbList',
    'itemListElement': items.map((item, index) => ({
      '@type': 'ListItem',
      'position': index + 1,
      'name': item.name,
      'item': item.url
    }))
  };
}
```
